# dxreadiness.data

This is the main repository with data and code used to update the [Pathogen Diagnostics Readiness Index (PDxRI)](https://www.finddx.org/data-and-impact/dashboards/diagnostic-readiness-index/#/).

Check the info in the [Outbreaks](https://github.com/finddx/dxreadiness.data/tree/main/outbreaks) folder for more details.
